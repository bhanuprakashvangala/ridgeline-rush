# Ridgeline Rush

An original 3D hill-climb trials game: ride a dirt bike up steep mountain trails, balancing throttle
and body weight so you don't flip. All code, 3D models, textures and sound are generated by this
project at runtime. Third-party code: three.js (MIT) and the Rajdhani font (SIL OFL), both free for commercial use.

## Play (Windows)
Double-click `Play.bat`, or open `www/index.html` in Edge/Chrome.

| Action | Keyboard | Gamepad | Touch |
|---|---|---|---|
| Gas | Up / W | RT or A | GAS |
| Brake / reverse | Down / S / Space | LT or B | BRAKE |
| Lean back / forward | Left / Right (A / D) | Left stick | lean buttons |
| Restart / Pause | R / Esc | Start | pause button |
| Fullscreen / Mute | F / M | | icons |

Too much gas on a steep climb loops the bike over backwards: lean forward and feather the throttle.
The BALANCE gauge shows your pitch relative to the ground. Flips take 1 s off your time.

## Fuel, coins and the Garage
- Fuel drains while you ride (faster on throttle). Grab red fuel cans to refill; run dry and the run ends.
- Coins (gold 5, silver 25, red 100) float along the trail; finishing pays a summit bonus by stars. Coins are saved.
- Garage: Engine, Tyres, Suspension, Fuel Tank, Rider Fitness (6 levels each), plus a Paint Shop.
- Tuning lives in `js/physics.js` (`RR.BALANCE`, `RR.UPGRADES`, `RR.PAINTS`, `RR.makeTune`) and pickup placement in `js/levels.js`.

## Graphics settings
Settings > Graphics: Low / Medium / High / Ultra. High renders at native resolution up to 2x pixel
density with 4096 shadow maps; Ultra renders at full native density (4K and above) with 2048 px textures.

## Develop
    npm install
    npm run build        # bundles src/ + js/ into www/game.js

- `js/levels.js`: themes + 12 mountains (seeded generator: climbs, walls, ledges, boulders, logs)
- `js/physics.js`: bike physics, crash detection, ragdoll (runs headless in Node too)
- `src/world3d.js`: renderer, sky, terrain, scenery, camera
- `src/bike3d.js`: 3D bike + rider
- `src/textures.js`: procedural PBR textures
- `src/ui.js`, `www/style.css`: menus and HUD
- Debug: `www/index.html?level=6&bot=1&skip=20` (autopilot, skip 20 s)

## Publish to Android / iOS (Capacitor)
`www/` is already a complete web app, so it can be used directly:

    npm i @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios
    npx cap init "Ridgeline Rush" com.yourname.ridgelinerush --web-dir www
    npx cap add android && npx cap open android      # needs Android Studio
    npx cap add ios && npx cap open ios              # needs a Mac with Xcode

Lock orientation to landscape (Android: `android:screenOrientation="sensorLandscape"`).
Store icons: export `www/icon.svg` to 512x512 (Play) and 1024x1024 (App Store) PNG.
Check the name "Ridgeline Rush" against the stores and trademark databases before publishing.
